# Industrial Anomaly Explainer — Research Showcase + Synthetic Demo

A Streamlit research showcase with two **distinct** components:

1. **Research Results** presents reported metrics and methodology from the original locally executed SWaT-based research prototype.
2. **Interactive demo** uses a separately trained synthetic-only Isolation Forest and SHAP to illustrate sensor anomaly workflows.

**The hosted application does not contain SWaT records, SWaT attack schedules, or SWaT-trained artifacts. Do not upload restricted SWaT data to the public repository or hosted CSV uploader.**

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Features

- Research Results (reported local SWaT precision, recall, F1 and average precision)
- Synthetic monitoring dashboard and observation inspection
- Absolute SHAP influence rankings
- Temporal and hypothetical disturbance context
- Methodology and limitations
- Anomaly explorer
- Manual sensor what-if controls, synthetic generator, CSV batch analysis and downloads

## Important interpretation notes

- Research metrics are **not** generated by the hosted synthetic model.
- SHAP absolute magnitudes reflect influence on TreeExplainer's internal model output, not causality or signed contributions to the displayed anomaly score.
- Synthetic disturbances are illustrative and are not actual cyberattacks or a validated digital twin.
- The original SWaT-based prototype is retained separately for authorised local demonstration.
